### CSP Headers Example (add to next.config.js):
```js
async headers() {
  return [
    {
      source: '/:path*',
      headers: [
        {
          key: 'Content-Security-Policy',
          value: [
            "default-src 'self'",
            "script-src 'self' 'unsafe-eval' 'unsafe-inline' https://vercel.live",
            "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
            "font-src 'self' https://fonts.gstatic.com data:",
            "img-src 'self' data: https:",
            "connect-src 'self' https://vitals.vercel-insights.com",
            "frame-ancestors 'none'",
            "base-uri 'self'",
            "form-action 'self'",
          ].join('; '),
        },
        { key: 'X-Frame-Options', value: 'DENY' },
        { key: 'X-Content-Type-Options', value: 'nosniff' },
        { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
        { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },

    },
```

## 4. GITHUB REPOSITORY SETUP

### Initialize & Push:
```bash
# 1. Initialize git (if not done)
git init
git add .
git commit -m "Initial commit: Portfolio v1.0"

# 2. Create GitHub repo
gh repo create jivanshu/portfolio --public --source=. --remote=origin --push

# 3. Or manually via GitHub web UI, then:
git remote add origin https://github.com/jivanshu/portfolio.git
git branch -M main
git push -u origin main
```

### Branch Protection (GitHub UI: Settings → Branches → Add rule for `main`):
- [ ] Require a pull request before merging
- [ ] Require approvals (1)
- [ ] Dismiss stale PR approvals when new commits are pushed
- [ ] Require status checks to pass before merging
  - [ ] `build` (GitHub Actions)
  - [ ] `lint` (GitHub Actions)
  - [ ] `typecheck` (GitHub Actions)
- [ ] Require linear history
- [ ] Include administrators

### Create `.github/workflows/ci.yml`:
```yaml
name: CI
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run lint
      - run: npx tsc --noEmit
      - run: npm run build

  # Optional: Add dependabot auto-merge for patch updates
```

3. Configure:

### Environment Variables (Vercel Dashboard → Settings → Environment Variables):
| Name | Value | Environment |
|------|-------|-------------|
| `NEXT_PUBLIC_SITE_URL` | `https://jivanshu.dev` | Production, Preview |
| `NEXT_PUBLIC_GA_ID` | (optional) | Production |

### Custom Domain:
1. Vercel Dashboard → Settings → Domains
2. Add `jivanshu.dev` and `www.jivanshu.dev`
3. Configure DNS at your registrar:
   - **A record**: `@` → `76.76.21.21`
   - **CNAME**: `www` → `cname.vercel-dns.com`
4. Enable "Redirect www to non-www" (or vice versa)
